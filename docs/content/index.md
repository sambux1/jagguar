# Jagguar

Jagguar is a library for single-server secure aggregation. It is under active development.

!!! warning
    This library is a work-in-progress and has not received an external security audit. It currently runs on a single machine. While the goal is for this to be a production-ready secure library, use with caution.

## API Reference

The API reference for the Rust library is found [here](https://docs.rs/jagguar).

## Currently Supported Protocols

- [OPA](https://eprint.iacr.org/2024/723.pdf) (semi-honest only)
